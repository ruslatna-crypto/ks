# Сайт Keramika Sintez (на основе infraks.ru)

Современная научно-техническая корпоративная веб-версия официального сайта научно-производственного центра **ООО «KERAMIKA SINTEZ»** ([https://infraks.ru/](https://infraks.ru/)).

Проект разработан на базе **React 18 + Vite + React Router DOM + Lucide Icons + Современный модульный CSS**.

---

## 🚀 Как запустить сайт

### Способ 1: В один клик через `start.bat` (Рекомендуемый)
Просто дважды кликните по файлу в проводнике:
```
start.bat
```
Файл запустит локальный сервер разработки Vite и автоматически откроет сайт в вашем браузере по адресу:
👉 **[http://localhost:5173](http://localhost:5173)**

---

### Способ 2: Через командную строку (Терминал)

1. **Запуск сервера разработки:**
   ```bash
   npm run dev
   ```

2. **Сборка production-версии:**
   ```bash
   npm run build
   ```

3. **Локальный просмотр production-сборки:**
   ```bash
   npm run preview
   ```

## ✨ Выполненная модернизация

Сайт преобразован в современный научно-технический ресурс инженерно-исследовательской компании при полном сохранении всех исходных текстов, данных и изображений:

1. **Цветовая система и стиль:**
   * Основные цвета взяты из оригинального векторного логотипа: глубокий научный индиго (`#2e3187` / `#3E4095`) и инфракрасный акцент (`#ed3237`).
   * Реализованы CSS-переменные: `--primary`, `--primary-dark`, `--accent`, `--text`, `--text-secondary`, `--background`, `--surface`, `--border`.
   * Светлый, высококонтрастный и чистый дизайн исследовательского института без избыточных декораций.

2. **Sticky Header & Mega-Menu:**
   * Шапка фиксируется сверху при скролле, плавно уменьшается и приобретает мягкую тень.
   * Раздел «Разработки» оформлен с выпадающим списком и оригинальными иконками.
   * Мобильное меню адаптировано под accordion.

3. **Модернизированный Hero Slider:**
   * 7 оригинальных тематических слайдов с оригинальными баннерами и значками спектра.
   * На каждом слайде отображается выразительный текстовый блок: категория, заголовок, краткое описание и кнопка `[Подробнее →]`.
   * Поддерживается плавная смена (fade/slide), пауза при наведении мыши, стрелки, точки-индикаторы и свайп на смартфонах.

4. **Новые структурированные блоки главной страницы:**
   * **«Наши разработки»**: сетка карточек с единой высотой, оригинальными фотографиями, мягким подъёмом при наведении и зумом картинки на 2–4%.
   * **«Инфракрасные технологии»**: обзор 6 ключевых направлений (сушка, тепличные технологии, стерилизация, медицина, ИК-излучатели, обработка материалов).
   * **«Инфракрасная сушка»**: раздельный блок с фото сушильного комплекса, списком ключевых преимуществ и кнопками перехода.
   * **«Трёхслойная ИК-плёнка»**: специализированный блок со спектральными данными (620–720 нм), фото и результатами полевых испытаний.
   * **«Научные разработки»**: блок доказательной базы со ссылками на 12 научных таблиц, клинические протоколы, стандарты ISO 9001 и видеолекции.
   * **«Контакты и консультации»**: блок реквизитов, интерактивная карта Ташкента (OpenStreetMap + 2GIS) и форма обратной связи.

5. **Статьи и научные материалы:**
   * Тексты разбиты на структурированные блоки: вводный акцент, разделы, таблицы, характеристики.
   * **Полноэкранный Lightbox**: при клике на любое изображение оно открывается в полноразмерном модальном окне с навигацией стрелками и закрытием по клавише `ESC`.
   * **Адаптивные таблицы**: 16 подробных научных и клинических таблиц с поддержкой горизонтальной прокрутки на мобильных устройствах.
   * **Breadcrumbs**: хлебные крошки на всех внутренних страницах.

6. **Поиск:**
   * Интерактивное модальное окно быстрого поиска по нажатию кнопки в шапке.
   * Отдельная страница `/search?q=...` с подсветкой категорий и найденных фрагментов текста.

7. **Страница 404:**
   * Стильная страница ошибки с кнопкой возврата на главную.
